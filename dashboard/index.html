How the AI keeps improving this

The loop an agent (or you) runs. Every run lands in the experiment log above.
  1. Change a parameter, or edit the rule in nyopen/strategy.py.
  2. Run a backtest. It logs params and metrics, then rebuilds this dashboard.
  3. Judge it on the out-of-sample columns, not the in-sample ones.
  4. Keep what holds up out of sample. Promote it to the defaults in Params.
  5. Refresh the data periodically so the hold-out keeps growing.
python -m nyopen.run download                 # refresh NAS100 1-minute history
python -m nyopen.run backtest --name base     # run + log + export dashboard
