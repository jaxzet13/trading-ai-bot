# Funded Account Playbook

`index.html` is the operating manual built on top of the dashboard's simulations: budget routes, the week-by-week plan,
the strategy as a daily procedure, a position-size calculator with the drawdown-cut lines, firm picks with simulated odds,
the scaling path, the rules that get payouts denied, and a daily checklist.

`data.js` is generated by `python -m nyopen.playbook` from `dashboard/data.json` (run `python -m nyopen.run export` first).
