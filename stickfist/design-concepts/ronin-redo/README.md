# Ronin redo

The old Rare Ronin was a clean neon outline, nothing like the reference images (real texture, one lone subject, black void or fog, hard rim light or blown-out glow, heavy grain). These three base images are prompted for that look (Figma GPT Image 2.5 Sunburst), then run through the Rare duotone ASCII style at 71,680 characters.

The crop option in tools/ascii2.py (crop=x0,y0,x1,y1 as fractions) zooms in on the subject so the character grid is spent on the figure. Without it a photographic frame at this resolution turns the figure into a blob.
