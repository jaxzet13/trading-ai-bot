# Four ASCII cards, four styles

| Rarity | Fighter | Style | Characters | Grid | Output |
|---|---|---|---|---|---|
| Common | Stitch | classic: 10 chunky symbols, bone on black | 2,816 | 64 x 44 | 1500x2100 |
| Rare | Ronin | glow duotone: 14 characters, blue to white | 71,680 | 320 x 224 | 3000x4200 |
| Epic | Grimm | VHS glitch: digits only, torn rows, magenta/cyan split, scanlines | 219,520 | 560 x 392 | 3000x4200 |
| Legendary | Reaper | iridescent: all 70 characters, oil-slick colour | 701,000 | 1000 x 701 | 4500x6300 |

The number printed on each card is the true character count (columns x rows, spaces included).
`*-fullres.jpg` is the real resolution; the plain `.jpg` is scaled to 1500x2100 for viewing.
Tool: tools/ascii2.py (`python ascii2.py ART OUT NAME CODE MARK STYLE COLS SCALE [black white gamma shift glow pad]`).
Base art: Figma GPT Image 2.5 Sunburst prompts for bold, bright, simple silhouettes on black (sources/).
