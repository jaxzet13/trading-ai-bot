Rule: every figure is a stick figure (round head, thin line limbs); the world around it is lit and grained like a photograph.
Base images: Figma GPT Image 2.5 Sunburst (sources/). Tool: tools/ascii2.py. New options this round: `crop` (zoom on the subject),
`thick` (thicken thin strokes so a small figure survives the grid), `pal` (colour palette).

## The type (one quiet line)

`NAME ----------------- 71,680 chars`, with the copy ID tiny underneath and its rarity cuts in red. No big number, no label.
`typo='line'` in tools/ascii2.py (alternatives: `quiet` = count only, `ledger` = one centred line).
Sizes at 600 dpi: name and count 46 px (about 5.5 pt), unit 24 px, copy ID 30 px (about 3.6 pt).
