# Figma-generated art (GPT Image 2.5 Sunburst)

Made in the Figma file "STIXX card tests" with the Figma MCP generate_image tool (model gpt-image-2.5-sunburst, 1024x1536). The prompt pattern: a lone stickman, standing still, facing the viewer, full body, low angle, dark rainy street, huge pale moon, ink outlines + flat cel shading, red the only accent, nothing else happening, no text.

The art is cropped to 5:7 and resized to 1500x2100, then base_cards.js adds the name and copy ID (namepos "bottom").

Note: Figma asset URLs expire after 7 days, so the full-resolution PNGs are saved here in art-only/.
