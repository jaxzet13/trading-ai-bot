# Colour study

Five colourways per ASCII style (palettes live in the PALETTES table in tools/ascii2.py; pass pal=NAME).

- classic (Common): bone, phosphor, amber, blood, ice
- duo (Rare): blue, magenta, acid, amber, blood
- glitch (Epic): violet, red, toxic, cyan, hot
- irid (Legendary): oil, fire, toxic, aurora, candy (hue range on the colour wheel)

The sheet is a reduced preview; cards/ has each one scaled to 1500x2100.
